# v17.8.5-RC2 验收报告（2026-09-05）

> 分支：`fix/v17.8.5-rc2`（基于 RC1 = b1d114e，15 个主题提交）。
> 性质：**工程性收口**。按复核要求，本报告只回应六项重点复核点 + 阶段执行清单，不宣称 v17.8.5 正式完成（全链从零重建仍被 legacy_v11 阻断，见 §K）。

## 〇、结论速览

- **Builder 现在能原生生成 RC1 手工修出的全部事实**：`_module_payloads` 统一走 record_status 生命周期（raw/active/excluded 三分），2026 用户模块 active-only，lite=8401 行（110 幽灵行退出一切用户口径），manifest 换 wanyu-metrics/v1 口径。
- **116 的审计语义在源头文件+生成器两层归零**，verifier 全投影检查 + 残留语义扫描。
- **门禁**：Verifier v2 = **294 passed / 0 failed**；check_release.sh 全绿；sources.lock 12 项（含目录 rollup）全一致且负向测试有效；三个浏览器烟测（maintainable / major_city / ui_upgrade）**全 PASS**；python 单测相对 b1d114e 基线**净减少 25 个失败**（49→24，剩余全部为 legacy_v11 环境挂）。
- 浏览器烟测还**逼出并修复了一个真实产品缺陷**：后台重渲染会吞掉用户正打开的详情抽屉（fa38717）。
