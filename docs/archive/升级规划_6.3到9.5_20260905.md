## 七、执行纪律（从 v17.7.0→v17.7.2 两天实战中固化）

1. **双设备接力改 Git 流**：P0.1 完成后，网盘只做备份不做传输通道，杜绝副本分叉。
2. **每批必过门禁**：check_release.sh 全绿 + verify 226+ + 相关 unittest，才允许登记版本号。
3. **批次节奏**：一批 3-5 人日、独立可验收、证据落盘 `docs/self-iterate/`（本批 Q2-Q5 模式已跑通）。
4. **多子代理并行**：数据线（构建器/干跑）与前端线（视图/SW）文件不相交时可并行，已验证有效。
5. **窗口红线**：P2 任何一项被挤占，优先砍 P3 内容，绝不推迟 T1。
