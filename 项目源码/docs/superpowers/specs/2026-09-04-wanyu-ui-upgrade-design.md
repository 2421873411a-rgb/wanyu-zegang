# 皖域择岗前端 UI 升级设计 · 2026-09-04

## 目标

把现有三年岗位维护站升级为更明确的岗位决策台，服务同一条真实任务链：筛选候选岗位 → 打开详情核对源字段与证据 → 收藏或加入对比。保持离线可用、源事实不改写、未知值不推断为零，并让 full-update、wan-lite、构建模板保持一致。

## 视觉方向

采用“河港蓝图”作为产品识别：像一张可复核的城市水系图，而不是通用 SaaS 仪表盘。

- 原本蓝色 `#3A83F7`：已命中、已保存、可继续的行动状态。
- 深蓝墨色 `#0F1D33`：导航、标题、证据层。
- 冷白雾蓝 `#F5F9FF`：页面画布，降低长时间阅读疲劳。
- 浅蓝底 `#E5EFFF` 与边界 `#DCE8F8`：承载筛选、步骤和可点击状态。
- 珊瑚 `#E26F5B`：竞争提醒与需要注意的状态，仅小面积使用。
- 琥珀 `#D99A4B`：来源边界、待核对等信息提示。

不引入远程字体或图标资源；保留系统中文字体与现有 mono 数据字体，确保离线一致性。

## 结构

### 桌面端

- 顶部改为轻量的“工作台壳层”：白底雾蓝渐变承载品牌、周期/考试口径、主导航和状态信息，`#3A83F7` 只用于高亮和主要行动。
- 岗位检索页增加可读的三段决策轨道：缩小范围、核对原文、保存/对比；统计条与筛选条件同一层级。
- 详情抽屉强化为“岗位档案”：头部显示岗位身份与状态，操作按钮固定在易触达区域，字段和来源分区阅读。
- 其他视图沿用同一组卡片、边界、标题与动作样式，不改动原有数据呈现逻辑。

### 移动端

- 隐藏拥挤的多行主导航，固定底部四项主任务与一个“更多”入口：总览、检索、地图、收藏；其余视图从“更多”抽屉访问。
- 岗位检索表在 680px 以下转为单行卡片，保留城市/单位/职位/专业/学历/招录/竞争/详情全部语义。
- 筛选控件改为单列可扫读区，底部安全区留白，详情抽屉全屏化但保留关闭和键盘焦点路径。
- `prefers-reduced-motion` 继续关闭非必要动效，焦点环保持可见。

## 签名元素

只保留一个强识别元素：岗位检索页的“决策轨道”。它对应真实的使用顺序，不添加与数据无关的装饰数字；当前阶段用蓝色信号点提示，行动完成后只提供轻量状态变化。

## 交互与数据边界

- 新增 UI 只读取现有 state、manifest、岗位行和本地工作台，不新增数据字段，不改变过滤、排序、保存、对比语义。
- “更多”导航只切换现有视图；移动卡片详情继续复用 `data-maint-position-detail`。
- 断点布局必须通过 390px 浏览器烟测；桌面与移动端都要检查无横向溢出、无控制项遮挡。

## 验收

- 新 UI 资产在模板、full-update、wan-lite 三处逐字节一致，并由构建器复制、Service Worker 预缓存。
- Python UI 契约测试通过；全部现有 v17 测试、Node 契约、JS 语法、磁盘校验和性能预算不回归。
- 内置浏览器真实验证：打开总览、进入岗位检索、窄屏底栏切换、打开岗位详情、返回并检查控制台无页面错误。
