# 皖域择岗 v17 升级计划

## 一、升级目标

将现有静态站升级为**高性能、可交互、用户友好**的现代化政务数据平台。

---

## 二、问题清单与解决方案

### 2.1 性能问题（高优先）

| 问题 | 现状 | 解决方案 | 预期效果 |
|------|------|----------|----------|
| 3Mbps上行瓶颈 | 首次加载122MB需30秒+ | CDN加速（EdgeOne） | 首屏<3秒 |
| 单文件61MB | 移动端打开慢 | 按需加载优化 | 体积减少50% |

### 2.2 用户体验问题（高优先）

| 问题 | 现状 | 解决方案 |
|------|------|----------|
| 无搜索历史 | 每次重新输入 | localStorage存储最近20条 |

| 移动端适配差 | 部分功能在小屏不可用 | 响应式重设计 |
| 无操作反馈 | 点击后无明确响应 | 添加Toast提示和加载动画 |

### 2.4 代码层面（中优先）

| 问题 | 说明 | 解决方案 |
|------|------|----------|

## 四、技术方案

### 4.1 CDN接入方案

```
用户 → EdgeOne边缘节点 → 回源到175.27.132.225
         ↓
    缓存静态资源（JS/CSS/JSON）
         ↓
    动态请求透传到源站
```

**配置要点：**
- 静态资源：缓存7天
- JSON数据：缓存1小时，ETag验证
- HTML文件：no-cache，每次回源

### 4.2 搜索历史方案

```javascript
// 存储结构
{
  "searchHistory": [
    {"keyword": "法学", "timestamp": 1693737600000},
    {"keyword": "计算机", "timestamp": 1693651200000}
  ]
}

// 功能
- 最近20条搜索记录
- 按时间倒序显示
- 支持单条删除和清空
- 搜索框获得焦点时显示
```

### 4.3 分享链接方案

```
原始URL: https://wan.kaogong.art/#jobs_search
分享URL: https://wan.kaogong.art/?cycle=2026&city=合肥&major=法学#jobs_search
```

**参数说明：**
- `cycle`: 周期
- `city`: 城市
- `major`: 专业
- `exam`: 考试类别
- `keyword`: 关键词
