# 皖域择岗总览 v6 设计规格

## 1. 产品定位

一个离线、证据优先的安徽 16 市择岗决策工作台。总览负责建立全局判断，机会地图负责岗位数据，待遇地图负责待遇数据，短名单负责保留选择，原始档案负责追溯来源。

## 2. 视觉语言

### 2.1 色彩

| 角色 | 色值 | 用法 |
| --- | --- | --- |
| 页面底色 | `#eef5fa` / `#fbfdff` | 轻雾蓝与纸白渐层 |
| 主标题 | `#11375e` | 大标题、关键城市名 |
| 主操作 | `#2f7de7` | 选中、跳转、主要按钮 |
| 机会色 | `#5594dc` | 岗位规模 / 机会点位 |
| 待遇色 | `#dfab53` | 待遇参考 / 高低提示 |
| 平衡色 | `#4faeb0` | 交叉数据与辅助点位 |
| 线条 | `#d5e4ef` | 分区、边界、表格分隔 |

### 2.2 版式

- 桌面最大宽度 1360px，首屏顺序为品牌导航、叙事标题、全局筛选、KPI、城市双轴工作台。
- 总览工作台使用“矩阵 + 画像”双栏；矩阵承载跨城市关系，画像承载当前城市事实和下一步动作。
- 移动端 390px 进入单列：筛选 → KPI → 活跃城市 → 矩阵 → 画像 → 短名单；不将桌面栏位机械缩小。
- 圆角主要使用 8 / 12 / 16 / 19px，阴影低对比，依靠线条和留白分层。

## 3. 信息架构

```text
全省总览
├─ 全局筛选
├─ KPI 摘要
├─ 城市机会 × 待遇矩阵
│  └─ 活跃城市画像
├─ 城市短名单预览
└─ 下一步引导
机会地图 / 待遇地图
我的短名单
└─ 城市选择 + 原岗位收藏 / 对比
原始档案
├─ 岗位 106 张源表
└─ 待遇 31 张源表
```

## 4. 状态模型

```js
{
  exam: '全部',
  type: '公务员',
  stage: '3年',
  city: '合肥',
  shortlist: []
}
```

- `exam` 只影响岗位数量、招录人数和竞争比。
- `type`、`stage` 只影响待遇序列。
- `city` 贯穿总览、岗位地图和待遇地图。
- `shortlist` 是当前浏览器本地状态，不上传、不跨设备同步。
- 非法参数回退到默认值；非默认状态通过 `history.replaceState` 留在 URL。

## 5. 双轴矩阵

- 横轴：当前考试类别下各城市岗位规模的相对位置。
- 纵轴：当前身份 / 工龄下待遇参考的相对位置，待遇越高越靠上。
- 点位位置使用 8%–92% 安全边界，避免贴边；点选点位后显示双层蓝色选中反馈。
- 默认只给活跃城市和前三相对位置城市显示标签，其他点位通过 hover / focus / title / aria-label 查看，避免 16 个标签在低密度区域互相覆盖。
- 图形下方明确提示相对位置不代表个人录用概率或收入承诺。

## 6. 动效规格

| 场景 | 动效 | 时长 |
| --- | --- | ---: |
| 视图切换 | 主视图上移淡入，导航当前态切换 | 420ms |
| KPI 重算 | 数字缓动，单位与上下文同步 | 330ms |
| 条件变化 | 点位位置和色彩平滑变化 | 200–420ms |
| 城市选择 | 点位放大、蓝色光圈、画像数字切换 | 180–360ms |
| 短名单 | 列表即时刷新，主按钮切换加入 / 移出态 | 180ms |

所有动效都在 `prefers-reduced-motion: reduce` 时取消过渡；不使用自动轮播、持续闪烁、粒子或强制镜头运动。

## 7. 内容边界

- 页面只把岗位与待遇两组源数据放到同一张“决策桌”，不生成未被源数据支持的综合推荐。
- “综合位置”是可解释的相对坐标展示，不是综合评分、录用概率或适岗建议。
- 待遇使用源报告估算中位数口径；岗位竞争比保持 `1:N` 展示，并注明计算口径。
- 原始档案视图保留全部源段落、表格、字段与目录定位。

## 8. 可用性与降级

- 所有主要动作使用按钮或链接，支持键盘焦点、`aria-label`、`aria-live` 或 `aria-pressed`。
- 矩阵点位为真实按钮；岗位 / 待遇旧地图继续使用项目内真实安徽 16 市路径。
- 关闭 JavaScript 后，源文档档案仍可阅读；页面不加载远程资源。
- 桌面 1280px、移动 390px 均要求页面级无横向溢出。
