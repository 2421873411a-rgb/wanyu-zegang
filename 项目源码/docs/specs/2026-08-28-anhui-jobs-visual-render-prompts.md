# 岗位机会观测台｜概念渲染图提示词

## 使用原则

- 这些图片只作为视觉参考，不直接裁切进最终网页。
- 如果生成工具支持参考图，请同时上传新版全包页的工作台截图，让模型继承其明亮、克制、专业的设计语言。
- 不要求图片模型绘制准确安徽边界或真实数据；地图和数字最终由代码生成。
- 建议先生成提示词 1 和 2，确定主方向后再生成移动端与动效分镜。
