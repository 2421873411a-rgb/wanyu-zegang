# 皖域择岗档案：安徽公考双网页设计规格

日期：2026-08-27  
状态：设计方向已确认，待用户审阅本规格后实施

## 1. 项目目标

将以下两份 Word 文档转换为两个无需服务器、可直接双击打开的独立 HTML 网页：

1. `安徽十六市2026软件工程可报岗位汇总_最终定稿版.docx`
2. `安徽全省16市本科普通岗全包分析_完善版(1).docx`

参考 `AI行测申论大模型横评报告.html` 的叙事节奏、吸顶导航、信息分层和交互完成度，但不复刻其考试卷视觉。双页形成统一品牌“皖域择岗档案”，同时保持不同的信息性格：岗位页服务于查找与筛选，待遇页服务于比较与核验。

## 2. 内容红线

- 完整保留源文档事实、标题、段落、表格、合并单元格、星号、破折号、置信等级、来源及风险说明。
- 不新增文档未给出的岗位、待遇、排名、结论、推荐标签或政策判断。
- 地图和图表只用于呈现源文档已有数据；城市位置明确为“导航示意”，不作为精确地理边界。
- 搜索和筛选只改变可见范围，不修改、推断或重算原始数据。
- 待遇页不得把估算值写成官方工资或个人收入承诺。

## 3. 统一视觉系统

### 3.1 设计方向

视觉主题为“城市情报台 × 研究档案”。质感来自精细网格、城市索引、克制的材质层、清晰的数据刻度和有目的的微动效，不使用常见的玻璃拟态大卡片堆叠。

### 3.2 色彩令牌

- 皖江蓝 `#173B57`：品牌主色、导航与标题
- 矿物青 `#2C7773`：交互、图形、正向强调
- 雾灰 `#EDF1EF`：页面底色
- 徽墨 `#182326`：正文与高对比信息
- 朱砂 `#C44F3F`：警示、当前状态与少量品牌签名
- 纸白 `#F9FBFA`：内容承载面

深色只用于局部封面和导航，不将整页做成高饱和霓虹界面。

### 3.3 字体与排版

- 展示标题：`STZhongsong` / `SimSun`，与粗黑体形成中宋黑混排
- 正文：`Microsoft YaHei` / `PingFang SC` / 系统无衬线
- 数据：`Bahnschrift` / `Cascadia Mono` / `Consolas`
- 主要内容宽度 1180–1280px；正文和说明行宽控制在易读范围；表格允许横向滚动。

### 3.4 共同组件

- 顶部阅读进度线
- 吸顶章节导航
- 当前章节高亮
- 返回顶部、打印按钮和两页互链
- 原文口径/风险说明使用固定语义样式
- 键盘可见焦点、`prefers-reduced-motion` 降级、打印模式

## 4. 页面一：十六市软件工程可报岗位

### 4.1 页面任务

让使用者快速回答：“哪些城市、考试类别和单位里存在软件工程专业可报岗位？”

### 4.2 首屏与辨识图

首屏使用“十六市档案航图”：

- 中央为自绘的抽象化安徽轮廓与水系视觉，仅作导航底图。
- 16 个城市节点显示城市名、岗位数和招录人数。
- 节点大小或外圈刻度仅映射源文档的岗位规模。
- 点击城市节点滚动至对应城市档案。
- 旁侧保留源文档总量 `544岗 / 825人` 及省考、事业单位、国考拆分。

地图不伪装成精确行政区划地图；页面明确标注“城市导航示意”。实现固定采用自行绘制的抽象“皖形坐标板”，不引用不明来源地图素材。

### 4.3 信息结构

1. 封面与十六市航图
2. 全省总览表
3. 搜索与筛选工具条
4. 十六市规模矩阵
5. 逐市档案
   - 城市摘要
   - 城市汇总表
   - 收录范围/数据口径
   - 按考试类别和单位批次划分的完整岗位表
6. 数据说明与页尾互链

### 4.4 交互

- 全文即时搜索：职位代码、单位、职位名及表格文字
- 城市筛选
- 考试类别筛选：省考、事业单位、国考及文档内实际分类
- 分类折叠/展开
- 一键清除筛选
- 命中数量反馈；无命中时显示明确空状态
- 城市矩阵和地图节点与对应城市章节双向联动

### 4.5 表格策略

- 保留所有 106 张源表和原始顺序。
- 表头吸顶，首列在宽屏上可保持可见。
- 手机端采用横向滚动和边缘提示，不把数值强行拆散成难以比较的卡片。
- 表格中的星号、空值、破折号和说明文字原样保留。

## 5. 页面二：安徽全省普通岗年度全包分析

### 5.1 页面任务

让使用者在理解估算口径和置信限制的前提下，比较城市、区县、身份类型与工龄节点，并获得报考前核验清单。

### 5.2 首屏与辨识图

首屏使用“待遇等高线 + 安徽薪资热力图”双层视觉：

- 等高线以源文档的刚入职、1年、3年、5年、10年节点绘制 16 市轨迹。
- 默认展示入职 3 年，与报告主要比较口径一致。
- 安徽城市热力图以 16 个城市导航区域着色，颜色只映射当前选中的源表中位数。
- 可切换公务员/事业编和工龄节点；图例始终显示单位为万元/年。
- 地图标注“城市级导航热力示意”，不表达精确区县边界。

### 5.3 信息结构

1. 封面、待遇等高线与薪资热力图
2. 报告说明与最重要口径限制
3. 置信等级 A–D
4. 16 市市直公务员/事业编对比
5. 市直梯队解释
6. 16 市逐城研究档案与区县表
7. 开发区与管理区观察
8. 工龄系数、乡镇补贴和全包构成
9. 数据核查结果与 2025 平均工资背景
10. 来源、风险提示、六项核验问题与原文结论

### 5.4 交互

- 公务员/事业编切换
- 工龄节点切换
- 城市搜索与快速定位
- 热力图、城市排名条和城市正文联动
- 置信等级筛选只用于突出/淡化，不隐藏口径说明
- 表格和图表提供可读的文本替代

### 5.5 图表约束

- 仅使用 Word 原表数据，不做插值预测或新增计算结论。
- 图表使用内嵌 SVG、HTML 和 CSS，不依赖外部图表库或 CDN。
- 公务员与事业编使用同一固定色阶定义，避免切换后产生误导。
- 对缺失或不可比较值明确显示“—”，不以 0 代替。

## 6. 数据转换与文件架构

目标目录：`安徽公考数据网页`

交付文件：

- `安徽十六市2026软件工程可报岗位.html`
- `安徽全省16市本科普通岗全包分析.html`
- `制作说明.md`

两份 HTML 均为单文件离线页面，CSS、JavaScript、SVG 和转换后的原文数据全部内嵌。两页通过相对路径互相链接，不要求安装 Node.js、Python 或浏览器扩展。

转换阶段从 Word 的底层 XML 顺序读取段落与表格，而不是分别读取后重新拼接，确保原文中段落和表格的交错顺序正确。超链接关系、表格合并信息和单元格文字也纳入转换。

## 7. 状态与错误处理

- JavaScript 不可用时，全部原始正文和表格仍然可阅读；仅筛选和动态图形不可用。
- 搜索无结果时显示筛选条件与清除入口。
- 图表数据缺失时保留原文表格并显示“图形不可用，请查看原始表格”。
- 不加载远程资源，因此不存在字体、脚本或图片 CDN 失败导致的空白页。

## 8. 动效原则

- 每页只设置一个主要动效：岗位页为城市节点依次点亮，待遇页为等高线从基准节点展开。
- 其余交互使用 160–240ms 的轻微状态过渡。
- 不设置阻挡内容的开场动画，不强迫用户等待。
- 系统开启减少动态效果后关闭位移和绘制动画。

## 9. 验收标准

### 9.1 内容核对

- 岗位页按顺序处理源文档全部 156 个段落节点、106 张表格及全部表格行；全部非空段落文本均可检索。
- 待遇页按顺序处理源文档全部 228 个段落节点、31 张表格及全部表格行；全部非空段落文本均可检索。
- 自动比对非空段落文本和单元格文本，报告缺失项。
- 标题、总量、城市数字、星号、来源和结论保持一致。

### 9.2 功能核对

- 搜索、筛选、清除、折叠、类型切换、工龄切换和城市定位可用。
- 无 JavaScript 降级时内容仍完整。
- 两页互链与打印模式可用。

### 9.3 浏览器与视觉核对

- Chromium 桌面端 1440×900
- 移动端 390×844
- 检查控制台错误、水平溢出、表格可读性、焦点可见性和减少动画模式
- 分段截图检查首屏、中段密集表格和页尾，不只验证代码或 DOM

## 10. 非目标

- 不联网核验或更新文档中的岗位与待遇数据。
- 不生成个人岗位推荐、自动排序结论或录取概率。
- 不制作需要部署的后端、账号系统或数据库。
- 不复制参考网页的角色头像、考试主题、配色或开场动画。
