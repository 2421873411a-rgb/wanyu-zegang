# 皖域择岗档案 · 观测台持续迭代设计

## 目标

在不改变源文档事实、估算口径和离线交付方式的前提下，降低移动端导航、深链参数、岗位对比和导出使用中的摩擦，并让这些行为有可重复的自动化验收证据。

## 约束

- 不新增岗位推荐、录取概率、竞争等级、城市综合评分或未经源数据支持的趋势结论。
- 不接入外部脚本、字体、地图服务或在线职位接口。
- 不改变 544 条岗位、825 人、16 市、106/31 张源表的事实数据。
- 未知 URL 参数必须回退到页面默认状态，不能让脚本因异常参数中止。
- 对比篮只恢复仍存在于当前页面数据集中的记录；导出保持 UTF-8 BOM、固定字段顺序并防止公式注入。

## 方案

1. **移动导航**：产品导航链接使用不可压缩的单项宽度和 `white-space: nowrap`，外层保留横向滚动；当前项仍有焦点和激活态。
2. **状态校验**：岗位和待遇页面分别使用白名单校验 `metric/exam/city/type/stage`；无效值回退，不修改源数据。
3. **岗位对比篮**：使用版本化 `localStorage` 键保存最多 4 条 `record_id`，恢复时过滤未知 ID；加入/移除/达到上限/清空均更新 `aria-live` 状态。
4. **检索可用性**：`/` 聚焦关键词框，`Esc` 只清空关键词；结果计数和筛选状态可读屏播报；复制摘要成功或失败显示明确反馈。
5. **安全导出**：CSV 单元格统一转义双引号并对 `= + - @` 开头的值增加前导单引号，避免电子表格公式执行。

## 验收

- Python 内容和数据测试继续全绿。
- bundled Playwright 的 7 页 smoke 继续全绿，并新增移动导航、非法深链、对比篮恢复、键盘快捷键、CSV 防注入断言。
- 390px、1024px、1440px 无页面级横向溢出；关闭 JavaScript 的档案页继续可读。
- 通过源码审计确认新文案不引入推荐性结论，页面仍不加载远程资源。
