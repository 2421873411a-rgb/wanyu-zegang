# 数据更新操作手册（新周期接入 SOP）

本手册说明如何把一个新招考周期（如 2027 国考、2027 省考、2027 事业单位联考）的数据接入皖域择岗档案，并重建三年单文件离线 HTML。当前正式入口为 `deliverables/皖域择岗总览.html`，历史周期数据默认不得覆盖历史参照。

## 前置条件

- 两份源 Word：《安徽十六市软件工程可报岗位汇总》（岗位）与《安徽全省16市本科普通岗全包分析》（待遇），放入 `source_docs/`，文件名在 `tools/anhui_web/data/manifest.json` 的 `sources` 中登记。
- Python 3.12 与 `requirements.txt` 依赖（python-docx 1.2.0、lxml 6.1.1）：`python -m pip install -r requirements.txt`。
- 可选：Node.js（运行纯函数测试与浏览器审计）、Chrome（审计脚本用系统 Chrome 通道）。
- 无源 Word 时无法重建；成品 HTML 仍可直接打开查看，测试会以 skip 跳过依赖源文档的用例。

## 接入流程

1. **归档声明**：为新产品周期在 `tools/anhui_web/data/` 登记 manifest（cycle、snapshot_date、sources、datasets、open_items），读取器为 `tools/anhui_web/cycles.py`；目录布局规划见 `docs/plans/2026-08-29-multi-cycle-workbench-v10.md` Task 2（`data/cycles/<cycle>/` 归档落地前，数据文件暂在 `data/` 根）。
2. **资格核查**：事业单位岗位逐条比对华图职位库备注，省考岗位逐条比对官方职位表"其他/经历要求/政治面貌"，产物存为根目录核查 JSON；随后运行 `python tools/anhui_web/build_eligibility.py` 合并生成 `data/position_eligibility.json`。身份定向岗（四项目/退役士兵/随军家属）人工复核后记入 `data/job_eligibility_exclusions.json`。
3. **构建**：先生成周期 sidecar（`python tools/anhui_web/build_cycle_data.py --year 2024 --year 2025`），再运行 `.\build.ps1` 或 `python tools/anhui_web/build_pages.py --jobs-docx <岗位docx> --salary-docx <待遇docx> --output-dir .\deliverables`。正式构建只生成 `deliverables/皖域择岗总览.html`，三个周期在站内切换。
4. **测试**：`python -m unittest tests.test_anhui_web -v`（内容完整性，含源段落/单元格逐项核对与定向核除断言）；`node --test tests/test_wanyu_core.cjs`（纯函数层）；浏览器审计 `node tests/audit_v9.js`（48 checks，需 playwright-core 与 Chrome）。
5. **发布**：`python tools/anhui_web/release.py --zip` 一键"测试 → 构建 → 同步 deliverables → 打包"；打包会把 `source_docs/` 一并收入（缺失时给出显式警告，禁止在缺源文档状态下分发对外交接包）。
6. **记录**：`HANDOFF.md` 追加版本日志；`python tools/anhui_web/gen_data_dict.py` 刷新 `docs/数据字典.md`；新截图入 `tests/artifacts/`，设计结论入 `design-qa.md`。

## 口径红线（不可变）

- 竞争比 = 招录人数 ÷ 考试人数，逐岗缺失时回退报名人数，页面显示 1:N。
- 不生成录用概率承诺、城市推荐结论或薪资预测；模拟输出必须标注"按源表入围线的估算"。
- 地图为数据导航用途，不替代法定行政区划图；薪资为源文档估算口径，非政策工资。
- 页面保持离线自包含；新增资源必须构建期内联。

## v14.0 长期维护站 SOP

### 目录约定

维护站输出固定为：

```text
deliverables/maintainable/
├─ index.html
├─ assets/maintainable-tokens.css
├─ assets/maintainable-site.css
├─ assets/maintainable-data.js
├─ assets/maintainable-site.js
├─ assets/maintainable-user-store.js
└─ data/
   ├─ site-manifest.json
   ├─ audit/three-year.json
   ├─ audit/review-queue.json
   └─ cycles/<cycle>/{overview,jobs,catalog,positions,scores,changes,audit}.json
```

`jobs.json` 是岗位源事实层；`catalog`、`positions`、`changes` 是由构建器派生的模块，禁止手改派生数字。`scores.json` 可以单独替换，但只允许安全关联结果进入岗位行，`keyed.unresolved` 必须原样保留。

### 新周期或新材料接入

1. 原始公告、PDF、XLSX、网页快照先保存到周期源目录，记录发布方、公告 URL/文件名、观察日期、源定位和 SHA-256；不得只保存截图中的手工数字。
2. 更新周期清单和审计边界。若官方资料不存在、只有汇总或无法唯一连接，状态写 `unpublished_or_unavailable` / `ambiguous_join`，值保持 `null`。
3. 依次执行：

```powershell
python tools/anhui_web/build_score_lists.py --cycle 2026
python tools/anhui_web/audit_three_years.py --root . --output-json tools/anhui_web/data/three_year_audit.json --report docs/三年数据真实性与完整性审计_v12.md
python tools/anhui_web/build_maintainable_site.py --root . --output-dir deliverables/maintainable
python tools/anhui_web/verify_maintainable_site.py deliverables/maintainable
```

4. 使用 HTTP 访问维护站：

```powershell
python tools/anhui_web/serve_maintainable.py --port 8765
# 浏览器打开 http://127.0.0.1:8765/index.html
```

5. 完成浏览器烟测后才更新交接文档、`MANIFEST.txt` 和 `CHANGELOG.md`。不要直接双击维护站 `index.html`；`file://` 下外置 JSON 会被浏览器安全策略阻止。需要双击查看时使用单文件离线回退入口。

### 每次发布必查

- manifest 的每个路径、字节数、SHA-256 与磁盘文件一致。
- 三年岗位数 28,678、招录 42,058、公开边界 8、成绩无法唯一匹配 116；若变化必须写明新增、修正或边界变化原因。
- 2024/2025/2026 每个周期七个模块齐全，`overview`、`catalog`、`audit` 不含完整岗位行。
- 专业候选不含纯数字/纯符号，组合筛选仍作用于原始 `zy`；详情可以回到源字段。
- `changes.json` 的语义候选必须显示待复核，不可显示为官方“同一岗位”。
- 运行 Python 单测、Node 契约测试、单文件浏览器烟测、维护站浏览器烟测和 ZIP 内部校验。

### 模块级回滚

回滚只允许使用同一版本发布目录中保存的同周期同模块文件。先复制当前模块为 `.rollback-backup`，再恢复目标文件，重建 manifest 并执行磁盘校验；校验失败立即恢复备份。禁止把 2025 模块拷到 2026，禁止跳过审计直接发布。

当前工作区无 Git 仓库，发布目录、ZIP 和 manifest 的 SHA-256 是回滚证据。若未来接入 Git，可将同一 manifest 作为提交前后的第二层校验。
