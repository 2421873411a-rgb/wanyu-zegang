# 皖域择岗档案 v3 优化执行计划

## 目标

在保留两个统一离线 HTML 文件、源文档逐字可回查和现有动态数据的前提下，降低长页面疲劳感，让每个视图更像一个可操作的数据产品。

## 设计决定

- 主视觉从“白色卡片堆叠”收敛为“地图 + 当前选择事实条”；蓝色只用于动作和选中状态，暖金色只用于待遇高值提示。
- 档案不是删数据，而是按城市/报告章节折叠；首屏只展示索引和摘要，展开后仍保留原表、段落和顺序。
- 对比只展示岗位数、招录人数、竞争比和待遇节点等事实，不生成推荐、竞争等级或综合评分；竞争比定义为招录人数 ÷ 考试人数，逐岗缺失时回退报名人数。
- 岗位检索与岗位对比分工：检索页保持表格阅读连续性；岗位对比作为同一 HTML 内的独立视图，通过最多 4 张事实卡集中查看，不再使用吸附抽屉遮挡列表。
- 动效只服务于状态变化：地图选中、数字更新、对比条出现；遵守 `prefers-reduced-motion`。

## 执行顺序

1. 先补充生成页面与浏览器验收测试，验证新标记和交互入口。
2. 为岗位/待遇档案增加目录、搜索和折叠面板，默认保持第一组内容可见。
3. 为岗位/待遇观测台增加事实条、地图 tooltip 和选择状态提示。
4. 为岗位/待遇排名增加对比摘要条和轻量 SVG/CSS 可视化。
5. 统一响应式、焦点、过渡与打印样式，重新构建两个主文件。
6. 用内置浏览器逐视图回归，并更新交接包与 QA 记录。

## 验收门槛

- 两个主文件仍可双击打开，输出目录仍只有 2 个正式 HTML。
- 岗位 544 条 / 825 人、待遇 31 张源表不变。
- 档案首屏出现目录，展开/收起不会丢失源文字。
- 地图选择后事实条、检查器、数值和 URL 同步；无黑色焦点框。
- 排名选择城市后出现事实对比可视化；最多 4 个城市。
- 1440px 与 390px 无页面级横向溢出，减少动效模式可用。
