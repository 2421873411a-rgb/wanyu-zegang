## 0. 一句话主张

把 v14.4 "干净的浅蓝工作台"升级为 **"数据驾驶舱(Data Cockpit)"**:保留浅色研究台的可信感与全部数据诚实边界,注入现代 AI 产品的视觉语言——大字排印 + 渐变强调 + 深色决策面板 + 玻璃浮层 + 克制动效;同时补齐命令面板、命名筛选视图、对比增强、派生指标四类功能,让"好看"和"好用"同轮落地。

**参考对标**

| 参考 | 借鉴点 | 不照搬的部分 |
|---|---|---|
| codex.0101.run(截图:`tests/artifacts/ref-codex-0101-hero.png`、`ref-codex-0101-full.png`) | 特大号黑体标题 + 第二行渐变文字;近白画布上的细网格纹理;黑色胶囊主按钮;深色数据小面板(深底 + 发光条形图 + 大数字);绿色呼吸状态点;玻璃拟态浮层卡 | 它的紫色主色、营销页节奏、订阅定价模块——与本产品"证据工作台"属性无关 |
| 2026 设计趋势(uiuxshowcase《21 Web Design Trends 2026》;ThoughtSpot dashboard best practices) | bento 网格组织信息;暗色主题成为标配;"动效解释功能"而非装饰;叙事驱动的数据可视化;高对比排版 | AI 个性化推荐等重前端方案(离线边界不允许) |

**红线(全程不可违背,来自 v14.x 交接约定)**

1. 不引入任何远程脚本/样式/字体/图片;离线单文件保持双击可用。
2. 单文件 < 80 MiB(当前 61.1 MB,余量约 19 MB)。
3. 数据诚实边界不动:未知不显示为 0;缺口、`未提供`、`安全留空` 的语义色不得改为"成功色"。
4. 不改 `jobs.json` 岗位原文;派生指标一律放新增 derived 模块,与原文分层。
5. 每阶段结束必须通过:磁盘校验 `verify_maintainable_site.py` 全绿、`maintainable_browser_smoke.js` PASS、Python 契约测试全绿;视觉层另加 `test_ui_v15` 契约。
6. 所有变更走 Git 提交;视觉层改动必须同时更新单文件注入层与维护站模板,两入口一致。

## 1. 现状诊断

### 1.1 UI(v14.4 实拍:audit-20260901 截图组)

| 问题 | 具体表现(对应截图) | 影响 |
|---|---|---|
| 视觉语言单一 | 全站只有"深蓝大标题 + 白卡 + 蓝数字"一种模式;六个视图几乎同构(14/16/17 截图) | 没有记忆点,用户分不清"在哪一层" |
| 缺乏排版张力 | 标题统一深靛实色;数字用同一字重;强调只靠加蓝 | 首屏说服力弱,不如参考站的大字 + 渐变冲击力 |
| 数据可视化贫乏 | 城市分布只有水平条;地图只有单色阶热力;三年对照只有表格 | 28,678 岗三年数据的结构洞察没被"画出来" |
| 无暗色主题 | 全站仅浅色 | 深夜查数据刺眼;深色也是数据面板聚焦感的载体 |
| 动效几乎缺席 | 周期切换、筛选变化无过渡;数字无滚动 | 状态变化不可感知,显得"静态截图" |
| 表格信息密度低 | 榜单 7 列全文本;竞争类数值无视觉编码(17 截图) | 扫读效率低,重点不突出 |
| 壳层功能弱 | 无命令面板、无快捷键提示、无主题开关 | 高频用户(多轮筛选对比)操作路径长 |

### 1.2 功能与数据(现状盘点后的缺口)

- 已有且保留:三周期切换、地图、榜单组合筛选、可读专业目录、检索、收藏/对比/备注(周期隔离)、分数模拟(仅可比口径)、审计中心、导出 CSV、URL 状态恢复、键盘周期切换。
- 缺口 ①:筛选组合不能"存下来复用"(每年报名期会反复用同一组条件)。
- 缺口 ②:对比只到 4 岗并排文本,没有差异高亮与"胜负判定"辅助。
- 缺口 ③:三年变化只能人工对比表格,没有派生"变化量/增幅/新增城市"层。
- 缺口 ④:没有全局命令入口;Ctrl+K 级别的效率工具缺失。
- 缺口 ⑤:116 条待复核成绩、8 项公开缺口只有审计页一处呈现,总览不可见进度。

## 2. 设计系统升级(Design Token v3)

### 2.1 主题架构

引入 **双主题**,由 `data-theme="light|dark"` 驱动,跟随系统 `prefers-color-scheme` + 手动开关 + `localStorage` 记忆 + URL `?theme=` 恢复。所有颜色一律走 CSS 变量,禁止硬编码色值(契入 `test_ui_v15` 断言)。

### 2.4 排印(离线约束:只用系统字体栈,零远程字体)

--font-mono:    "Cascadia Code", Consolas, "Sarasa Mono SC", monospace  (代码/职位代码/哈希)

字阶(桌面/移动):

| 级别 | 桌面 | 移动 | 用途 |
|---|---|---|---|
| display-xl | 44px/1.15, 800 | 30px | 每视图 hero 标题(第二行可用渐变) |
| display | 30px/1.25, 700 | 22px | 区块标题 |
| title | 18px, 600 | 16px | 卡片标题 |
| body | 14px/1.6 | 14px | 正文 |
| label | 12px, 500, +0.04em 大写英文小标签 | 同 | "CYCLE OVERVIEW" 式眉标(保留现有特色并强化) |
| metric-xl | 40px, 800, tabular + 渐变(仅 hero KPI) | 28px | 核心大数字 |

### 2.5 空间/圆角/阴影/层级

- 间距基准 4px;卡片内边距 20/24;区块间 32/40;网格 gap 16。
- 圆角:`--radius-sm 8 / md 14 / lg 20`(不变)+ 新增 `--radius-pill 999`(胶囊按钮)。
- 阴影三档:`soft`(现有)、`lift`(hover 浮起 `0 12px 32px rgba(15,40,90,.14)`)、`glow`(仅暗色 hero 数字/图表,`0 0 24px rgba(91,155,255,.25)`)。
- 玻璃卡 token:`background: color-mix(in srgb, var(--bg-surface) 78%, transparent); backdrop-filter: blur(14px); border: 1px solid color-mix(... border 60%)` —— 用于地图检查器、命令面板、详情抽屉。
- z-index 层级表:content 0 / sticky-head 10 / drawer 40 / palette 50 / toast 60。

### 2.6 材质与纹理(纯 CSS,零图片)

- 画布细网格:`repeating-linear-gradient` 两方向 1px 线,透明度 3%,48px 网距(参考站的格子质感,暗色下降至 2%)。
- 渐变光斑:hero 区右上 `radial-gradient` 淡蓝光斑,暗色下为深蓝光晕。
- 状态点呼吸:`@keyframes pulse`(2.4s,"部分证据已核验"徽标使用,`prefers-reduced-motion` 关闭)。

### 2.7 动效系统(原则:动效解释功能,不做装饰)

| Token | 值 | 用途 |
|---|---|---|
| `--dur-fast` | 120ms | hover/按下反馈 |
| `--dur-med` | 220ms | 抽屉、面板展开 |
| `--dur-slow` | 420ms | 周期切换、视图过渡 |
| `--ease` | `cubic-bezier(.22,.61,.36,1)` | 全局缓动 |

具体编排:
1. 周期切换:旧数据 crossfade + 新数字从下方 8px 浮入 + KPI 数字滚动(count-up,仅变化时)。
2. 列表(榜单/检索翻页):首屏 8 行 stagger 20ms 进入;后续翻页不重复(防烦)。
3. 地图:指标切换时色阶 420ms 过渡;城市 hover 描边 + 检查器玻璃卡滑入。
4. 筛选:chips 增删 spring 缩放;结果计数变化闪一次高亮。
5. 骨架屏:周期 JSON 懒加载期间,目标卡片显示 shimmer 占位(替代现在的空白等待)。
6. 全部动效包一层 `@media (prefers-reduced-motion: reduce)` 直通开关(现有约定延续)。

## 3. 分视图 UI 规格(逐视图 before → after)

### 3.1 全局壳层

- **顶部**:两行改"一行sticky玻璃条"——品牌标 + 视图导航(中) + 周期胶囊切换器(右,保留 2024/2025/2026 + 键盘 ←/→);右端新增:主题开关(日/月图标)、`Ctrl+K` 提示、数据状态点(绿=已核验/琥珀=有缺口,呼吸)。
- **导航**:当前项由"下划线"升级为"胶囊底色 + 渐变文字";移动端横向滑动保留。
- **新增命令面板(Ctrl+K / 长按徽标)**:玻璃卡居中浮层,模糊搜索:视图跳转、岗位(按代码/名称/单位)、城市、周期切换、主题切换、清空筛选。结果分组 + 方向键选择 + Enter 执行。纯本地索引(构建期生成 `palette-index.json`,≤1MB)。
- **页脚**:保留"外置 JSON 维护站 · 单文件离线快照"入口,新增构建版本 + 数据快照日期 + 审计状态一行(数据从 manifest 动态读,延续 v14.4 做法)。

### 3.2 周期总览(现 14 截图)

- 改 **bento 网格**(12 栏):hero 标题区(跨 8 栏,大字排印 + 第二行渐变)+ 证据状态玻璃卡(跨 4 栏,含呼吸状态点和"116 待复核"进度环)。
- KPI 行 4 卡改为 bento 内不等宽:岗位总数、招录人数两枚 **metric-xl 渐变大数字** + 环比箭头(如 2026 vs 2025:岗位 −16.2%,数据来自 derived 层);省考/事业编/国考构成改为 **堆叠横条**(一根条看三源结构)。
- 城市岗位分布:条形图升级为 **条 + 三年 sparkline 复合行**(hover 显示三年数值);保留"打开岗位榜单"跳转。
- 数据边界卡:缺口数、待复核数用 `--warn`,点击直达审计中心对应锚点。

### 3.3 岗位地图(现 16 截图)

- 新增 **暗色地图模式**(主题为 dark 时地图自动跟随):深底 + 发光色阶(蓝→青),参考站深色数据面板质感;light 下维持现有蓝色单色阶。
- 色阶从 5 档纯蓝改为 **两套可选**:岗位数(蓝系)、招录人数(蓝→青系);图例加"省直独立口径"固定提示。
- 城市检查器改为 **右侧玻璃浮层**(现在贴边白卡):城市名 metric 字号、岗位/招录/三年趋势 mini 折线、"在岗位检索中查看"胶囊按钮;支持拖拽改停靠左右。
- 城市索引卡(下方 17 宫格):数字 tabular + 相对全省均值的小色点(高于/低于均值),hover 浮起。
- 交互不动:点击→检索联动、键盘 Enter/Space、省直独立,均保持。

### 3.4 三年对照

- 顶部新增 **坡度图(slope graph)**:三列(2024/2025/2026)× 17 地区岗位数,线段升降即趋势;hover 高亮单城并联动下方表格行。
- 考试结构、成绩匹配率、缺口数各加一条 **三分段堆叠条** + 差异徽标(如"2026 省考岗位 −8.1%")。
- 证据层/源包调整维持折叠卡,但折叠头加语义色点(绿/琥珀/灰)。

### 3.5 岗位榜单(现 17 截图)

- 筛选面板改为 **单行工具条 + 展开抽屉**:常用(关键词、城市、考试)常驻;专业/岗位类型/排序收进"更多筛选"抽屉;活动条件以 chips 显示在工具条下(点击 × 移除,"全部清空"胶囊在右)。
- 表格重排:
  - 排名列:前 3 名金银铜徽标(01/02/03 圆牌),其余灰。
  - 岗位数/招录数:右对齐 tabular;新增 **占比内联条**(单元格背景 12% 高度蓝条,长度=占全省比)。
  - 新增"竞争可比性"列:仅显示 `ratio_comparable` 的城市给"招录/岗位比"数值 + 色阶点;不可比显示灰色"— 不可比"(数据诚实红线:绝不显示猜测值)。
  - 行 hover 浮起 + "查看岗位"按钮显形。
- 表尾:结果数 + 每页条数 + 分页;翻页 stagger 动效。

### 3.6 岗位检索

- 沿用榜单新工具条(两视图共用组件);结果表支持 **密度切换**(舒适/紧凑)。

- 分页大库(万行级)性能:保持现有分页渲染,新增"跳至页码"输入。

### 3.7 岗位详情(改造为 **右侧滑入抽屉**,不再整页切换)

### 3.8 收藏与快照 / 对比

## 5. 数据层升级

1. **derived 模块**(F5)字段草案:
   ```
   { cycle, generated_on,
     vs_prev: { jobs_delta, hires_delta, by_exam: {...} },
     city_trend: { "<city>": { y2024, y2025, y2026, cagr_like_note } },
     mix: { shengkao, shiyebian, guokao },        // 构成比
     ratio_comparable_rate,                        // 竞争可比率
     review_progress: { resolved, total } }        // 来自 review queue
   ```
   规则:所有派生值可由现有模块重算复现(写入"计算说明"字段);源包调整(如 2026 的 +54 岗)在 derived 注释层保留标记,不混入官方数。
2. **palette 索引**:`data/palette-index.json`(岗位代码/名称/单位 → job_id),构建期生成,SHA-256 入 manifest。
3. **116 待复核 & 8 缺口**:结构不动;仅新增展示层读取。后续若官方补发,仍走既有"源文件 → 构建 → 审计 → manifest"链路。
4. **schema 演进纪律**:jobs.json 字段冻结;新需求一律 derived/sidecar;manifest 记录每模块 `schema_version`(从 v1 升 v2 仅 overview/derived)。
