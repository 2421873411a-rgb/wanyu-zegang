## 一、参考站动效系统拆解（已从其 CSS 实证）

| 手法 | 参考站实现 | 当前站点差距 |
|---|---|---|
| 滚动显现 | `.reveal`：opacity 0 + **opacity .78s / transform .92s 双时长**；4 方向变体（left/right ±34px+scale(.99)、scale=translateY(18px)+scale(.955)、top）；交错 `transition-delay: var(--reveal-delay,0s)`，阶梯 .14–.48s（约 70ms/步） | 只有单方向 translateY(14px) 420ms 单段，无方向变体，仅 bento 4 格交错 |
| 缓动 | 主 `cubic-bezier(.2,.8,.2,1)`；弹入 `cubic-bezier(.16,1,.3,1)`（模态 .35s slideUp） | 只用一组 --ease |
| 环境循环 | chip-float 3.2s、core-float 1.8s、status-pulse、辉光扫描、吞吐柱 | 只有骨架 shimmer |
| 浮层入场 | 模态 slideUp .35s pop 缓动 | 详情抽屉/命令面板瞬现 |

## 二、本轮范围（v16.2，全部进既有 reveal-ready/is-in 基建）

### M1 显现系统升级

- 新令牌（:root，动效类不随主题，与既有 --dur-* 同层）：
  `--dur-reveal: 780ms`、`--dur-reveal-x: 920ms`、`--ease-pop: cubic-bezier(.16,1,.3,1)`。
- 区块显现升级为位移+微缩放（translateY(16px)+scale(.985)→原位），时长用 --dur-reveal；
  方向变体：`.maint-grid` 左列 reveal-left / 右列 reveal-right（对开感）。
- 结构化交错（纯 CSS nth 阶梯，不加 JS）：
  hero 子元素 eyebrow→h1→lede→stamp 0/70/140/210ms（stamp 用 scale 变体）；
  bento 4 格、审计 KPI 4 卡、变化卡、指南 3 步、CTA 内层 3 行。
  60 行检索表格不做逐行动画（噪音+性能）。

### M2 数据生长动效（真实数据红线兼容）

- 占比条 scaleX(0→1) 生长（`.city-row i em`、`.num-bar i`，transform 合成器动画不重排，city-list 8 行阶梯延迟）；
- mixbar 分段依次生长；
- sparkline 描线：JS `sparkline()` 加 `pathLength="1"`，CSS dashoffset 1→0；
- 地图区域入场：激活已存在的 `--map-delay`（v14 遗留，CSS 从未消费），`.is-in` 后按 22ms/区交错淡入；指标切换重渲染自然重放；
- 榜单前三奖牌 pop、delta 徽标滑入。

### M3 浮层入场与微交互

- 详情抽屉：backdrop 淡入 + 抽屉滑入 .38s pop（≤600px 底部抽屉改 translateY）；命令面板 slideUp .35s；
- CTA 带：同心圆 20s 慢呼吸/旋转（纯装饰）；`(pointer:fine)` 指针跟随辉光（--pointer-x/y）；
- CTA 主按钮箭头 hover 右移 3px（build 里包一层 `<i>`）；bento 格与变化卡 hover 上浮 2px + 阴影抬升（hero stamp 已有 tilt，排除）；
- 页头底部 2px 滚动进度线（build 加 span + JS rAF 节流 scaleX；reduced-motion 下无过渡仍可用）。
