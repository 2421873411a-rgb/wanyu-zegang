## 1. 北极星目标（v17 定位）

把「证据档案台」升级为 **「又快、又有温度、仍可复核」的择岗决策工作台**：

1. **快**：首屏 < 2s 可见内容、切周期/切视图无感；把带宽瓶颈交给边缘/压缩，而非堆体积。
2. **活**：动效让数据「长出来」，但绝不因动效掩盖数据缺失（终值=真实数据）。
3. **真**：每个数字都能回到源文件；未知保持未知，不粉饰。
4. **贴**：更懂用户意图——从「看数据」到「做决定」的短路径（地图→待遇→检索→收藏→导出）。

## 2. A · 设计系统与视觉（Design System v4）

### 2.1 设计令牌（Token v4）
- **数据可视化色板独立成组**：`--viz-heat-*`（热力 6 档，现已有）、`--viz-trend`（sparkline）、`--viz-rank-1/2/3`（奖牌）、`--viz-status-*`（verified/source_bundle/derived/unpublished/ambiguous/needs_review 语义色）。**语义色不可用于装饰**。
- **成对令牌全覆盖**：浅色/深色各一套 6 位 hex；新增 surface 分层（bg-context/surface/sunken/glass），暗色观测台单独打磨发光点。
- **类型阶梯**：Display/H1–H4/Body/Caption/Eyebrow/Mono（数字专用等宽，对齐表格与排行）。
- **间距 8pt 网格 + 圆角/阴影/描边令牌**，统一卡片、抽屉、面板呼吸感。

### 2.2 品牌与色彩
- 主色仍 `#3a83f7`（用户确认不变）；辅助色只承担数据语义与状态，不抢主视觉。
- 为「待遇」定义专属点缀色（区别于岗位数的蓝，可用暖琥珀/青），形成「蓝=岗位、琥珀=待遇」的心智区分（仅用于标签与图例，热力主图仍走单色阶以保持可比）。

### 2.3 状态与空态体系
- 统一五态：**空（无数据）/ 加载（骨架）/ 成功 / 错误（可重试）/ 降级（reduced-motion / 离线）**。
- 「未取得 / — / 未单列披露」三套文案规范，绝不出现 0 冒充。
- 骨架屏从条形升级为「视图语义骨架」（地图轮廓骨架、表格骨架、卡片骨架）。

### 2.4 图标与图形
- 内联 SVG 图标集（视图导航、指标、导出、键盘、主题），随主题令牌变色；不引外部字体/图标库（守无远程资源）。

### 2.5 对比度与可访问
- 现仅 band 做 ≥4.5 数学回归；v4 扩到**全部成对令牌**（WCAG AA），暗色态 ≥ 3:1 大字体。
- 色弱友好：热力图增加「图案/描边」可选开关，不只靠颜色深浅。

## 5. D · 动效 / 动画（重点深挖）

### 5.1 设计原则
1. **终值=真实数据**：动画只是把终值「长」出来，不许编造中间假数据。
2. **可降级**：`prefers-reduced-motion: reduce` / 无 JS / 弱设备 → 直出终态。
3. **不牺牲性能**：只用 `transform`/`opacity`（合成层），避免触发布局；60fps 目标。
4. **动效服务认知**：生长=数据加载完成，渐变=指标切换，位移=视图切换。

### 5.2 动效清单（分优先级）
- **数据生长**：占比条/构成条 `scaleX` 生长、排行榜条从左生长、sparkline 描线（pathLength）、count-up（终值字节级=真实值）。【已有，扩到待遇排行条】
- **地图**：区域按 `--map-delay` 交错淡入 + 描边；**指标切换时热力色阶平滑过渡**（fill 过渡 0.3–0.4s）；悬停抬升 + 投影。【新增：切换过渡】
- **视图转场**：视图切换用淡入 + 轻位移（≤12px，不扩横向滚动区）；避免整页跳变感。
- **浮层微交互**：抽屉/命令面板入场 0.38s pop、CTA 圆环呼吸、页头滚动进度线、卡片 hover 抬升。【已有，打磨】
- **滚动驱动显现**：`.reveal-ready` 按能力注入，IntersectionObserver 分批进场，交错错峰。【已有，量化时长】
- **骨架→内容交叉**：骨架淡出与真实内容淡入 0.2s 交叉，避免闪烁。

### 5.3 动效预算
- 单视图首屏动画总时长 ≤ 900ms；交错间隔 ≤ 40ms；禁用 >600ms 的阻塞动画。
- 明确禁用：会让用户以为「数据还在变」的循环动画用于真实数值；对「未取得」做数字滚动。

### 5.4 实现约束
- 全 CSS 变量 + `transform/opacity`；JS 仅负责加 `.is-in` 与终值写入。
- 每处动效都有对应 reduced-motion 直出路径，并纳入契约测试。

## 6. E · 动态数据 / 数据流水线

### 6.1 更新流程可视化
- 把「数据更新清单」做成**带进度环的向导**：登记来源→重建→校验→走查→发布，每步可勾选（本机持久化）、可复制命令，**且不替代磁盘校验结论**。
- 增加「最近更新时间线」：每周期最后构建/来源/审计时间，公开可见。

### 6.2 增量与新鲜度
- 数据模块增加 `freshness` 元数据（周期快照日期）；页面顶部「数据更新于 …」徽标。
- 支持**模块级替换**（单周期单模块换文件 + 重建 manifest + 跑校验），避免整包重发。

### 6.3 传输层（治卡顿，最高优先）
- 上 **CDN/边缘**（腾讯云 EdgeOne 或 Cloudflare）托管静态，绕开 3Mbps 上行。
- nginx：**brotli**（JSON 比 gzip 再省 ~15%）+ **HTTP/2** 多路复用 + `Cache-Control: public, max-age=31536000, immutable`（带版本资源）。
- 大模块（scores/changes）确认仅按需加载（已确认 scores 客户端从不加载），避免无谓首发。

## 7. F · 性能与加载（硬预算）

### 7.1 首屏关键路径
- 目标：首屏内容绘制 < 2s（边缘）/ < 5s（源站）。
- 首屏只拉：`site-manifest` + `overview` + `jobs_lite` + `map` 几何；其余（jobs/scores/positions/catalog）按需。

### 7.2 体积预算（压缩后，单周期）
| 模块 | 现状(压缩后) | 目标 | 手段 |
|---|---:|---:|---|
| jobs_lite | ~0.66MB | <0.6MB | 精简冗余字段、短键 |
| jobs | ~1.2MB | 按需 | 仅详情加载 |
| catalog | ~0.65MB | <0.5MB | 压缩目录 |
| positions | ~0.57MB | 按需 | 仅检索加载 |
| scores | 0（客户端不拉） | 维持 | 确认不拉 |

### 7.3 手段
- `jobs_lite` 进一步裁剪（去掉详情页才用的字段）；地理几何全局共享不重复；地图路径压缩坐标小数位。
- 对资产用 `preload`（CSS/JS）、对下一视图用 `prefetch`（低优先）。
- 建立**性能预算门禁**：构建后输出各模块压缩体积，超阈值报警。

## 12. K · 红线与「不做清单」（Negative Space）

**必须遵守**
- 岗位原文不改；未知/未发布/无法唯一匹配 → null，不用 0。
- 离线无远程资源；单文件 < 80MiB。
- 省直独立口径，不伪造「省直市」；待遇为 2026 快照、地市级，不下探区县、不混读分母。
- 成绩跨量纲不比较；竞争比混合分母不参与排名/推荐。

**明确不做（避免过度设计）**
- 不做「待遇/岗位数性价比排名」等诱导误读的伪指标。
- 不做会暗示实时/官方逐岗工资的文案。
- 不为动效引入外部库（守无远程资源）。
- 不把无法唯一匹配的成绩强行绑定岗位。
